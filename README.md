## Description

Open-source universal ESP for Roblox with player highlighting and real-time information overlay.

**Open Source** — This script is completely open source. Feel free to modify, improve and customize it!

 Distributed under **GNU General Public License (GPL)**.

## How it Works

The ESP automatically detects all players in the server and displays useful information above them.

### Player Information

* **Player Name** — Displays the player's username.
* **Health** — Shows current and maximum HP.
* **Distance** — Displays the distance to the player in meters.
* **Team Colors** — Highlight colors automatically match the player's team.

The script also automatically supports:

* New players joining the server.
* Character respawns.
* Team changes.

## Features

* Universal player ESP
